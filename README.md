# projeto-integrador-frontend-cristiandiego
Sistema administrativo para gerenciar o pet shop de banho e tosa da família,
facilitando o dia a dia do negócio. O projeto contará com uma tabela de valores
dos serviços oferecidos, um controle simples de receitas e despesas do mês, e
uma calculadora de simulação de taxas para pagamentos em cartão, ajudando a
entender o valor líquido recebido por cada venda. O objetivo é centralizar
essas informações em um só lugar, de forma prática e visual.
